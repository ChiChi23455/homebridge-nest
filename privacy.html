Privacy Policy

This policy covers the Homebridge Nest personal integration. This integration is used only by its owner, for the owner's own Google Nest thermostat. It is not an official Google or Nest service.

Google user data accessed

With the owner's authorization, the integration uses the Google Smart Device Management API to read the owner's thermostat information as available. This includes status, temperature, humidity, mode, and device and structure identifiers. The integration also sends the thermostat controls the owner authorizes.

How it is used and shared

  • Thermostat data is used only to show and control the owner's thermostat in the owner's Homebridge server and Apple Home.
  • Data is shared only as required for Google's API, Homebridge, and Apple Home to operate under the owner's authorization.
  • Thermostat data is not sold and is not used for advertising. This site uses no third-party analytics.

This website

These pages are static and hosted on GitHub Pages. They have no sign-in, forms, cookies, or analytics, and they do not collect credentials. GitHub, as the hosting provider, logs visitors' IP addresses for security purposes under the GitHub Privacy Statement (https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). The owner does not use these logs.

Revoking access

The owner can revoke this integration's access at any time in their Google Account under third-party connections (myaccount.google.com/permissions).
