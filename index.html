Homebridge Nest – Personal Integration

This is a private, personal-use integration. It connects the owner's own Google Nest thermostat to the owner's own Homebridge server at home, so the thermostat can be viewed and controlled in Apple Home.

This is not an official Google or Nest website, and it is not affiliated with or endorsed by Google.

What it does

  • Uses the Google Smart Device Management (SDM) API, only with the owner's authorization.
  • Reads the owner's thermostat information as available, such as status, temperature, humidity, mode, and device and structure identifiers.
  • Sends only the thermostat controls the owner authorizes, for example mode or target temperature changes made from Apple Home.

This site has no sign-in and no forms, and it does not collect any account or thermostat credentials.
